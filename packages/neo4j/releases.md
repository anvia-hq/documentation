# Releases

## `1.0.0`

Anvia v1 introduces `@anvia/neo4j` with schema-first extraction, managed and existing graph registrations, document-scoped writes, vector and hybrid retrieval, bounded traversal, provenance evidence, and an Agent graph-search tool.

The current stable release is **1.0.0**.

Review the package [source](https://github.com/anvia-hq/anvia/tree/main/packages/graph-neo4j) and [changelog](https://github.com/anvia-hq/anvia/blob/main/packages/graph-neo4j/CHANGELOG.md).
