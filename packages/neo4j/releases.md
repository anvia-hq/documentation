# Releases

The current stable release is `@anvia/neo4j` **1.0.4**.

| Version | Summary |
| --- | --- |
| `1.0.4` | Adopted the shared raw-text ingestion and reusable graph/vector embedding helpers. |
| `1.0.3` | Adopted provider-neutral schemas and Agent tools, added portable bounded exploration, and aligned retrieval with the shared graph contracts. |
| `1.0.2` | Updated for explicit cancelled-run finalization in Core. |
| `1.0.1` | Refreshed supported upstream dependencies. |
| `1.0.0` | Introduced schema-first extraction, managed and existing graph registrations, document-scoped writes, vector/hybrid retrieval, bounded traversal, provenance evidence, and Agent graph search. |

Review the package [source](https://github.com/anvia-hq/anvia/tree/main/packages/graph-neo4j) and [changelog](https://github.com/anvia-hq/anvia/blob/main/packages/graph-neo4j/CHANGELOG.md).
