# Releases

The current stable release is `@anvia/neo4j` **1.1.0**.

| Version | Summary |
| --- | --- |
| `1.0.12` | Updated the Core dependency to `1.0.10` and the Graph dependency to `1.0.12`. |
| `1.0.11` | Updated the Core dependency to `1.0.9` and the Graph dependency to `1.0.11`. |
| `1.0.10` | Added property-level graph-extraction conflict resolution with structured warnings and errors, durable ingestion receipts with optional graph-plus-vector orchestration, explorer source provenance, and shared-resource tenant namespaces. |
| `1.0.9` | Updated the Core dependency to `1.0.8` and the Graph dependency to `1.0.9`. |

| `1.0.4` | Adopted the shared raw-text ingestion and reusable graph/vector embedding helpers. |
