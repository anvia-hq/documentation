# Releases

## `1.0.0-rc.3`

The v1 RC introduces `@anvia/neo4j` with schema-first extraction, managed and existing graph registrations, document-scoped writes, vector and hybrid retrieval, bounded traversal, provenance evidence, and an Agent graph-search tool.

The current published manifest is **1.0.0-rc.9**. Changes described as next RC are available from `staging` and publish with the next synchronized release commit.

Review the package [source](https://github.com/anvia-hq/anvia/tree/staging/packages/graph-neo4j) and [changeset](https://github.com/anvia-hq/anvia/blob/staging/.changeset/add-neo4j-graphrag.md).
