# Releases

## `1.0.0-rc.3`

RC3 introduces `@anvia/neo4j` with schema-first extraction, managed and existing graph registrations, document-scoped writes, vector and hybrid retrieval, bounded traversal, provenance evidence, and an Agent graph-search tool.

The SDK branch still carries RC2 manifest versions until the synchronized RC3 release commit is prepared.

Review the package [source](https://github.com/anvia-hq/anvia/tree/v1-rc3/packages/graph-neo4j) and [changeset](https://github.com/anvia-hq/anvia/blob/v1-rc3/.changeset/add-neo4j-graphrag.md).
