# Releases

## `1.0.0-rc.3`

RC3 introduces `@anvia/browser` as an explicit Docker-backed Chromium runtime with semantic tools, a noVNC desktop, Studio integration, and coordinated human takeover.

The package is new in the RC3 code line. The SDK branch still carries RC2 manifest versions until the synchronized RC3 release commit is prepared.

Review the package [source](https://github.com/anvia-hq/anvia/tree/v1-rc3/packages/tool-browser) and [changeset](https://github.com/anvia-hq/anvia/blob/v1-rc3/.changeset/add-browser-runtime.md).
