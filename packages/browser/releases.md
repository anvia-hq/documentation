# Releases

## `1.0.0-rc.3`

The v1 RC introduces `@anvia/browser` as an explicit Docker-backed Chromium runtime with semantic tools, a noVNC desktop, Studio integration, and coordinated human takeover.

The current published manifest is **1.0.0-rc.9**. Changes described as next RC are available from `staging` and publish with the next synchronized release commit.

Review the package [source](https://github.com/anvia-hq/anvia/tree/staging/packages/tool-browser) and [changeset](https://github.com/anvia-hq/anvia/blob/staging/.changeset/add-browser-runtime.md).
