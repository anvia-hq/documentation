# Advanced

Use advanced capabilities when an agent needs runtime control, specialized coordination, or isolated execution.

## Capabilities

| Capability | Focus |
| --- | --- |
| [Dynamic context](/sdk/advanced/dynamic-context) | Request-time facts, retrieval, and permissions. |
| [Hooks and run control](/sdk/advanced/hooks) | Lifecycle hooks, cancellation, and tool control. |
| [Multi-agent systems](/sdk/advanced/multi-agent) | Specialist agents, coordination, and boundaries. |
| [MCP](/sdk/advanced/mcp) | Remote tool servers, transports, and trust. |
| [Skills](/sdk/advanced/skills) | Reusable instructions, references, and tools. |
| [Dynamic tools](/sdk/advanced/dynamic-tools) | Runtime tool retrieval and tool sets. |
| [Think tool](/sdk/advanced/think-tool) | Deliberate intermediate reasoning. |
| [Parallel and batch](/sdk/advanced/parallel-and-batch) | Concurrent branches, batches, and workers. |
| [Multimodal](/sdk/advanced/multimodal) | Image, audio, transcription, and OCR. |
| [Sandbox execution](/sdk/advanced/sandbox) | Isolated file and command execution. |
